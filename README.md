# SSTONet

**Space Systems Thermal Operator Network**

SSTONet studies topology-aware surrogate modeling for satellite temperature-field prediction under varying operating and thermal-contact conditions.

## Release status

This repository is a public placeholder for SSTONet. The source code, trained model weights, and access to the associated dataset will be made publicly available through this repository after the manuscript is accepted for publication.

The SSTONet research release is not yet available.

## Related project

[NXOpen_satellite](https://github.com/Ne1ther/NXOpen_satellite) provides Siemens NX / Simcenter 3D thermal-analysis automation, including parameter updates, batch simulations, solve orchestration, and result export. It is a separate automation codebase and does not contain the SSTONet models, trained weights, or research dataset.
